# Cambridge PET Flashcards

An illustrated PET-only course for young learners, based on the official August 2025 Cambridge B1 Preliminary and Preliminary for Schools Vocabulary List. Every KET headword is removed before the course is built.

## What is included

- 1,461 PET-only A–Z entries, from `ability` to `zone`
- Zero KET overlap, including the official `suprising` typo for KET `surprising`
- 25 letter groups, 7 official word sets, and 22 PET-only topic lists
- A stationary, click-to-continue Congratulations page after every letter group
- One rich KET-style storybook clue on every front: textured painterly scenes, gentle odd creatures, muted jewel colours and tender theatrical light
- One fixed, loud, natural British-female neural headword recording
- One or two short Chinese glosses
- One 2–8-word plain-English meaning
- One short example sentence
- Perfectly level clue frames on every screen
- Fixed, zero-scroll AWL-style practice flow with saved progress and light/dark themes

## Local use

```bash
npm install
npm test
npm run dev
```

The Cambridge list is the source for entry selection and 121 complete official examples. This is an unofficial learning aid and is not endorsed by Cambridge.
